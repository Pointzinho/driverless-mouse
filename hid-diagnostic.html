Sondagem manual — Feature Reports

Para dispositivos que não disparam inputreport sozinhos (comum em mouses baratos com firmware simples). Varre Report IDs de 0x01 a 0x20 via receiveFeatureReport().

Logitech · HID++ 2.0

Envia um pacote HID++ 2.0 padrão (Report ID 0x10/curto) para o Root (feature 0x0000): função GetProtocolVersion (Ping) e GetFeature para Adjustable DPI (0x2201) e Unified Battery (0x1004). Respostas chegam como inputreport no mesmo Report ID e aparecem no log/grade normalmente — filtre por 0x10 se necessário. Detectado automaticamente ao conectar um VID 0x046d.

0xff = cabo/receptor direto. Se o mouse estiver pareado via receptor Logitech Bolt/Unifying, troque para 01, 02...

Enviar Comando HID++ Customizado

Monta e envia um pacote HID++ 2.0 curto (0x10) à mão, usando o mesmo Device Index configurado acima. Útil para explorar funções dentro de uma feature já localizada (ex: feature idx 07 = Adjustable DPI, descoberta no handshake) sem precisar editar o código a cada tentativa.

Log bruto
Clique em Conectar mouse, selecione o dispositivo na caixa do navegador, depois abra o software oficial do fabricante (ou use os botões físicos de DPI/perfil do mouse, se houver) e altere um valor por vez.

Se nada aparecer sozinho, use os painéis de sondagem manual à esquerda — muitos mouses só respondem quando o host pergunta primeiro.

Cada byte que mudar vai piscar em âmbar na grade acima — esse é o offset que controla aquele valor.
